# Daily Fetal Movement Tracker

A React Native application to track fetal kicks and movements. This app works entirely offline, storing session data locally.

## Features
- **Home Screen**: View history of movement sessions (Date, Time, Duration). Includes a static article section.
- **Counter Screen**: Live timer and kick counter.
- **Local Storage**: Data persists across app restarts using AsyncStorage.
- **Info Sheet**: Modal with instructions on how to track movements.
